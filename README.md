# LGD Glossary — Candidate Definitions for

## Part IV — Re-evaluation vocabulary (specified in themes#33, 2026-10-01; demonstrated in lgd-medai-demo)

**Restore condition** — the structured commitment registered at the moment a downgrade takes effect, recording what will permit reinstatement: the evidence list that must arrive, the role entitled to verify it, and the validity window within which that verification holds. A downgrade without a restore condition is a one-way gate; with one, restoration is a governed transition rather than an ad hoc pardon. Where recovery semantics are absent from a statute, its drafters can only write the one-way version (see eIDAS Art. 28(4): a revoked certificate "shall not in any circumstances be reverted"). Evidence: *runnable* — lgd-medai-demo reaches `REVERIFY → RESUMED` on a re-verification gate; opened as an open question in [themes#33](https://github.com/FG-TIDA/themes/issues/33) (2026-10-01), with sector practice reviewed in the same thread.

**Re-evaluation-ready record** — a decision record that carries the inputs the original decision was based on, not only its outcome, so that a later re-evaluation evaluates against the authored reference rather than from memory. A record of outcome without inputs supports reconstruction ([themes#1](https://github.com/FG-TIDA/themes/issues/1)) but not re-decision. Evidence: *specified* — defined in [themes#33](https://github.com/FG-TIDA/themes/issues/33) (decision provenance for re-evaluation, 2026-10-01); demonstrated in lgd-medai-demo (gate decisions recorded with their inputs).

**Stale decision** — a governed decision marked as no longer current without thereby being reversed. Staleness is a status distinct from revocation: the decision's validity window has closed, while its record remains authoritative about what was decided and on what inputs. Evidence: *specified* — themes#33 (currency and decay, 2026-10-01); the validity-window motif is present in population-scale evaluation practice ([themes#21](https://github.com/FG-TIDA/themes/issues/21)).

**Eligibility state machine** — the formal object in which eligibility is a first-class variable: a state set (active / restricted / suspended / retired / reinstated), transitions triggered by evidence events, a gate predicate on each transition, and a restore condition attached to every downgrade. Evidence: *runnable* — demonstrated in lgd-medai-demo (`DENIED → GATE_PASSED → PAUSE → ROLLBACK → REVERIFY → RESUMED`, single command, zero dependencies); the research skeleton is developed in the LGD theory work (2026-10-01).
