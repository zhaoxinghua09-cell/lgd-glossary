# Security Policy / 安全策略

## Supported versions / 支持版本

Only the latest `main` branch is supported.

## Reporting a vulnerability / 报告漏洞

**Please do NOT open a public issue for security vulnerabilities.**

- Email: **zhaoxinghua09@gmail.com** (owner: 赵兴华 / Steven Zhao·China)
- Include: reproduction steps, affected commit SHA, impact assessment.
- Expect an initial response within 7 days.

请勿就安全问题开公开 issue，请直接邮件联系上述地址，并附复现步骤与受影响 commit SHA。
